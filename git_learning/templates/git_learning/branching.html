What is a Branch?

Imagine you're writing a book. You want to try a different ending without losing your original. You make a photocopy (a branch), write the new ending on the copy, and decide later which version you prefer. If you like the new ending, you merge it back into the original. In Git, branches work the same way — safely isolated copies of your code.

Essential Git Branch Commands

Creating & Switching Branches

# Create a new branch (a copy of current branch) git checkout -b feature/my-feature # Or with newer Git syntax: git switch -c feature/my-feature # Switch to an existing branch git checkout main git switch main # List all branches (* = current) git branch

Merging & Keeping Up to Date

# Merge another branch INTO current branch git merge feature/my-feature # Get latest changes from the remote server git pull origin main # Update your branch with latest main changes git rebase main # Delete a branch (after merging) git branch -d feature/my-feature
