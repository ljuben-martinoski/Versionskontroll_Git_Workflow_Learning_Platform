How to Make a Great Commit (Step by Step)

1

Stage your changes

Tell Git which files to include in this commit

git add src/auth/login.py # Add specific file git add . # Add ALL changed files (use carefully)
2

Review what you're committing

Always check what you're about to save

git status # See which files are staged git diff --staged # See the exact line changes
3

Write a meaningful commit message

Use the Conventional Commits format

git commit -m "feat(auth): add password reset via email" # Format: type(scope): description
4

Push to the remote repository

Upload your commit to GitHub/GitLab

git push origin feature/add-password-reset
