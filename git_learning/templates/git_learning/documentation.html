Essential Git Commands Cheat Sheet

🏁 Getting Started

# Initialize a new repository in current folder git init # Clone (download) an existing repository git clone https://github.com/user/repo.git # Configure your identity (done once) git config --global user.name "Your Name" git config --global user.email "you@example.com"

📸 Staging & Committing

# See what's changed (what Git is tracking) git status # Stage a specific file for committing git add filename.py # Stage ALL changed files git add . # Commit staged changes with a message git commit -m "feat: add user login page" # Stage and commit in one step git commit -am "fix: correct form validation"

🌿 Branches

# List all local branches (* = current) git branch # Create new branch from current git checkout -b feature/new-feature # Switch to existing branch git checkout main # Merge another branch into current git merge feature/new-feature # Delete a branch (after merging) git branch -d feature/new-feature

🌐 Remote Repositories

# Add a remote (usually done automatically with clone) git remote add origin https://github.com/user/repo.git # Download changes (don't merge yet) git fetch origin # Download AND merge latest changes git pull origin main # Upload your commits to remote git push origin feature/my-branch

⏪ Undoing Things

# Fix the last commit message (before pushing!) git commit --amend -m "corrected message" # Undo last commit but KEEP the changes git reset --soft HEAD~1 # Undo last commit and REMOVE the changes (careful!) git reset --hard HEAD~1 # Discard changes in a file (revert to last commit) git checkout -- filename.py

🔍 History & Logs

# See commit history git log # Compact one-line view git log --oneline # See a visual branch graph git log --oneline --graph --all # See what changed in a specific commit git show abc1234 # Search commits by message git log --grep="feat"

Git Glossary for Beginners

Repository (Repo)
The folder that contains your project AND all its Git history. Like a project folder with superpowers.
Branch
A parallel copy of the code where you can make changes without affecting the main version.
Commit
A saved snapshot of your code at a specific point, with a message describing what changed.
Merge
Combining changes from one branch into another. Like merging two documents into one.
Remote
The version of your repository stored on a server (e.g., GitHub). Your "backup in the cloud."
Clone
Downloading a repository from a remote server to your local computer.
Push
Uploading your local commits to the remote server (GitHub/GitLab).
Pull
Downloading the latest changes from the remote server AND merging them into your local copy.
Pull Request (PR)
A formal request to merge your branch into another. Teammates review the code before it's accepted.
HEAD
Git's pointer to the current commit you're working on. Like a bookmark in your commit history.
Staging Area
A waiting room for changes before they're committed. You choose what goes in before saving.
Merge Conflict
When two developers changed the same line differently — Git asks a human to decide which version to keep.
